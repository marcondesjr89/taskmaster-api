# 🚀 TaskMaster Core API

API para gerenciamento de tarefas desenvolvida durante a formação FullCycle de Engenharia de Software.

## 🛠️ Tecnologias
- **Linguagem:** Java 21
- **Versionamento:** Git & GitHub (Conventional Commits, Git Flow, GitHub Projects)
- **Containerização:** Docker

## 🎯 Objetivos de Engenharia
- Modelagem de Domínio com Encapsulamento Forte (POO).
- Aplicação de boas práticas de Clean Code e SOLID (Single Responsibility Principle).
- Ciclo de vida de containers com Docker.
- Fluxo de trabalho rastreável via Issues e Pull Requests.
